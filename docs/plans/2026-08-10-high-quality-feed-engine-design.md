## 1. 市场与产品定位（为什么做这三块）

跨境常见链路：**1688 货源 → Shopify 独立站 → Google Shopping / PMax**。

| 痛点 | 若不处理 | 本引擎要做的事 |
|------|----------|----------------|
| 中文堆砌标题 / 机翻 | CTR 差、关键词不匹配 | AI 按 Google 权重结构重构标题，并展示前后对比 |
| 缺 size/color/gender | GMC 服饰类拒批 / Limited | 分层抽取 + Google 允许的万能兜底 |
| 无 GTIN | 标识符拒批 | `identifier_exists=false` + 稳定 brand（无码免签） |
| 激进敏感词 | Adult / Misrepresentation → **封号** | 软化改写 + 主动 `adult=yes` |
| 1688 水印 / 牛皮癣图 | 拒审 + CTR 崩 | **I03 检测 + 用户从商品图库自选主图**；不修图 |

**竞品差距：** DSers 等铺货工具解决「货上架」；我们解决 **「上架后的广告 Feed 能不能过 GMC、会不会封号」**。

---

## 2. 目标 / 非目标

### 2.1 目标

1. 生成的 Feed **字段齐全、格式符合 GMC 机审习惯**，尽量在上架 Google 前消灭「缺属性 / 无码 / 脏词 / 脏图」。  
2. 所有自动动作 **可解释、可回看、可改**（优化日志 + 高亮微调；完整抽屉可后置）。  
3. **护号优先于激进投放**：宁可贴 `adult`、软化文案，也不把账号赌在灰色词上。  
4. 价币种与落地页一致（禁止静默换汇）—— 沿用已定设计。

### 2.2 非目标（本阶段）

- 不保证账号 100% Approve（运费、认领、套餐多货币等店外因素）。  
- 不伪造 GTIN。  
- 不把动态 URL、安检舱大动画、批量 Magic Bar 作为本阶段阻塞项。  
- 不做短视频 / B2B / 认证厂过滤。

## 3. 已拍板决策（与你笔记对齐后的统一口径）

| 主题 | 决策 | 说明 |
|------|------|------|
| 尺码兜底 | Feed 写 **`One Size`** | 语义 = 你说的 OSFA / One Size Fits All。Google 接受 One Size / OSFA；对外统一 **One Size**，避免 `0SFA` 笔误；内部把 OSFA/Free Size/均码 **归一成 One Size** |
| 颜色兜底 | 真色优先；最后 **`Multicolor`** | 可选次选 **`As Shown`**（配置开关，默认 Multicolor） |
| 颜色来源 | **变体 → LLM 读标题+HTML 描述 → 兜底** | 禁止一上来全店 Multicolor |
| gender / age / condition | 空则 `unisex`（可按类目改）/ `adult` / `new` | 隐性标签，默默写入 + 日志邀功 |
| 无码 | `identifier_exists=false` | 不造条码 |
| brand | **可读品牌 > 店名 > 自定义域名（如 my-store.com）> DEFAULT_STORE_BRAND** | **禁止** `*.myshopify.com`。你笔记里的「域名」指 **校准后的独立站域名**，不是 myshopify 后台域名 |
| FATAL 行 | **仍写入 Feed** | 报告标红；不叫「绿通」 |
| 敏感 | 软化 + 必要时强制 `adult=yes` | 护号优先 |

```

│ 1. 标题 AI 重构（广告专用 title）                   │
│ 2. 描述清洗 / 英文化 / 长度（可与标题同批）          │
│ 3. GPC / 品类判定（服饰 vs 其它）                   │
│ 4. 隐性标签：condition / age_group / gender         │
│ 5. 颜色：变体 → LLM 抽取 → Multicolor/As Shown      │
│ 6. 尺码：变体/规则 → 空则 One Size（仅服饰类）      │
│ 7. 无码通道：无 GTIN → identifier_exists=false + brand │
│ 8. link：真 variant id + currency（若已有能力则保留） │
└───────────────────────┬───────────────────────────┘
                        │
                        ▼
┌─────────────────── S6 敏感合规 ───────────────────┐
│ 9. 敏感词检测（标题/描述/标签）                      │
│ 10. 高危 → AI/映射软化改写                          │
│ 11. 敏感类目 → 强制 adult=yes                       │
│ 12. 无法软化的极危 → FATAL 标记（仍进 Feed）         │
└───────────────────────┬───────────────────────────┘
                        │
                        ▼
┌─────────────────── S7 图片（已收敛，2026-08-12）──────┐
│ 13. 主图风险检测（I03：脏 CDN / 启发式）               │
│ 14. **用户从 Shopify 图库自选** feed_image_url         │
│ 15. **不做** AI 去水印 / 白底 / OCR（已移出产品）       │
└───────────────────────┬───────────────────────────┘
                        │
                        ▼
        QualityReport + 优化日志 + 写出 XML/CSV
                        │
```

## 5. S1 — 数据内核（详细）

### 5.1 GMC 必填与「机审习惯」字段

| 字段 | 要求 | 引擎动作 |
|------|------|----------|
| `id` | 稳定唯一（通常 Shopify variant / SKU 策略） | 保持现有 ID 策略；禁止空 |
| `title` | 英文；禁止堆砌；Google 权重高 | **AI 重构**（§5.2） |
| `description` | 合规长度；准确 | AI 清洗；过长截断带 WARN |
| `link` | 可打开的落地页 | 带 `variant=` + `currency=`（已有则强化） |
| `image_link` | 清晰主图；忌中文水印 | S7 |
| `price` | `金额 + ISO 币种`；与落地页一致 | 价币种门；禁止静默 FX |
| `availability` | 仅 `in_stock` / `out_of_stock` | 由库存推导 |

### 5.2 标题 AI 重构（Title Restructuring）

**痛点：**  
`2026跨境新款女装法式复古碎花连衣裙V领显瘦沙滩裙` → 机翻仍垃圾，CTR 差。

**Google 偏好结构：**

```text
[Brand] + [Gender/Age 信号] + [Product Type] + [Attributes: Color, Size, Material, …]
```

**输出示例：**  
`eprolo French Vintage Floral Dress for Women - V-Neck Chiffon, Red, One Size`

**规则：**

1. 去掉年份、跨境、新款、显瘦等 **广告垃圾堆词**。  
2. 英文；关键词自然，禁止 keyword stuffing。  
3. 把已确定的 color/size（若有）编入标题属性段（与 Feed 字段一致，避免标题写 Red、字段写 Multicolor）。  
4. 长度：遵守平台上限（Google title 建议 ≤150 字符量级，具体跟现有 `title_guard`）。

**UX（最小必备，属 S1 价值证明）：**

| 展示 | 说明 |
|------|------|
| 原标题 | Shopify / 导入原文 |
| Google 广告专用标题 | AI 输出 |
| 一键采用 / 改回原标题 | 行级 |

用户看到对比 = 感知「工具超值」。

### 5.3 品类分流

```
判定 google_product_category / GPC / 标题启发
        │
        ├─ 服饰 / 鞋服 / 配饰 ──► 强制检查 size, color, gender, age_group
        │
        └─ 其它（3C / 汽配 / 日用等）
              ├─ 跳过「缺 size 必拒」逻辑
              ├─ 仍写 condition / age_group 等通用默认
              └─ 强调 brand + GTIN/MPN；无则走无码通道（不可假装有条码）
```

### 5.4 颜色逻辑（必须分层，禁止一刀切）

**目标：** 字段非空过机审 + 尽量准，提升匹配与体验。

| 步 | 来源 | 行为 |
|----|------|------|
| 1 | Shopify 变体 option / metafield | 有合法英文色则直接用 |
| 2 | **LLM 文本逆向** | 读 **标题 + HTML 描述**（含中文色名） |
| 3 | 词典兜底（可选轻量） | 黑→Black 等常见映射，减 LLM 成本 |
| 4 | 万能兜底 | **`Multicolor`**（默认）或配置为 **`As Shown`** |

**LLM Prompt 核心逻辑（设计级）：**

> 分析商品文本，找出颜色。若有中文（黑色、军绿、藏青）译为标准英文色（Black, Army Green, Navy Blue）。若完全无颜色信息，返回字符串 `Multicolor`。

**约束：**

- 有真色 **绝不**优先 Multicolor。  
- LLM 返回 Multicolor / 空 → 记 **WARN/AUTOFIX**，再写兜底。  
- 混色明确描述（「多色拼接」）→ Multicolor 合理。

### 5.5 尺码逻辑（服饰类）

| 步 | 行为 |
|----|------|
| 1 | 变体 / option 有 S/M/L/数字码 → 规范化写入 |
| 2 | 空 → Feed 写 **`One Size`**（= OSFA / 均码） |
| 3 | 日志：「已自动修补缺失尺码 → One Size」 |

非服饰：不因缺 size 判 FATAL。

### 5.6 隐性标签（Smart Meta-tagging）

即使店里没设变体，Feed **后台强行**写入：

| 字段 | 默认 / 规则 |
|------|-------------|
| `condition` | `new` |
| `age_group` | 空 → `adult`（童装类目另规则时可覆盖） |
| `gender` | 类目/标题启发 → `female` / `male` / 默认 `unisex` |

日志邀功示例：「已补齐 Google 必查标签：condition=new, age_group=adult, gender=unisex」。

### 5.7 1688 无码免签通道

**条件：** 无有效 GTIN（及业务上视为无条码）。

**动作：**

1. `identifier_exists` = **`false`**（强制）。  
2. `brand` = 按 §3 优先级填充（**禁止 myshopify.com**）。  
3. **不**伪造 UPC/EAN。

**日志（必须邀功，不可纯黑盒）：**

> 已为您激活【1688 无条码绿色通道】：`identifier_exists=false`，brand=「xxx」。已免除 GMC 条码硬性审查路径，降低拒批风险。

**3C / 汽配等：** 有 GTIN/MPN 则如实填；没有则同样走无码，**不可**假装有全球统一条码。

### 5.8 价币种（内核门禁，已定）

- 目标国要求的币种与店铺展示币不一致 → **该国不生成**，提示改 Shopify 市场/币种。  
- `price` 带 ISO；与落地页一致。  
- 细节见价币种设计文档。

### 5.9 QualityReport（S1 必须产出的数据合同）

```text
quality_report:
  light: green | yellow | red
  summary: { autofixed, warnings, fatals }
  autofixed[] / warnings[] / fatals[]:
    { rule_id, field, sku, before?, after?, message }
  checklist[]: 店外事项（运费、认领等）— 可选
```

**亮灯：** 有 FATAL→红；仅有 WARN/AUTOFIX→黄；全过→绿。

**本阶段 App 最小呈现（不必等完整安检舱）：**

1. 摘要：「已自动修补 N 个缺失尺码；已激活无码通道；已软化 M 条敏感词；已处理 K 张脏图」  
2. 优化日志列表  
3. 标题前后对比（抽样或分页）  
4. **高亮微调表**：只列出被自动兜底的行（size=One Size、color=Multicolor、adult 等），允许改保存后重生成/补丁写回 Feed  

完整右侧抽屉 / Magic Bar → 后置，不阻塞 S1。

## 6. S6 — 敏感词与合规过滤器（详细）

### 6.1 专业痛点

1688 灰色/敏感品类常见：塑身内衣、情趣内衣、户外战术刀具、按摩枪等。  
原始描述翻译后常带 **激进词** → 触发 Google **Adult / 违禁 / Misrepresentation** → 轻则拒批，重则 **封 GMC**。

### 6.2 引擎角色

**合规过滤器**，不是「尽量刺激点击」的文案机。

### 6.3 两层动作

#### A. 关键词软化（高危词）

| 示例原文语义 | 改写方向 |
|--------------|----------|
| Tactical Combat Knife / 战术防身刀 | Outdoor Camping Tool / 户外野营工具 |
| 过于露骨的情趣描述 | 中性内衣/服装描述 或 触发 adult + 软化 |

- 检测范围：重构前原文 + 重构后标题/描述（防 AI 又写出高危词）。  
- 实现分期：  
  - **S6a：** 可运营中英词表 + 映射改写（快、可控）  
  - **S6b：** LLM 上下文软化（覆盖长尾）  
- 每次改写写入优化日志：`原文 → 改写`，级别 AUTOFIX 或 WARN。

#### B. 主动贴标 `adult=yes`

| 判定 | 动作 |
|------|------|
| 内衣 / 情趣向 / 明确成人向类目或强信号 | Feed **强制** `adult=yes` |
| 目的 | 广告仅成人向展示，但 **保护账号不被误判封禁** |

日志：「已为敏感类目注入 adult=yes（主动合规，护号优先）」。

### 6.4 分级

| 级别 | 条件 | Feed | 灯 |
|------|------|------|-----|
| 可软化 | 词表/AI 可安全改写 | 用改写文案 | 黄（告知） |
| 贴 adult | 类目敏感但可售 | 文案软化 + adult | 黄 |
| 极危无法合规 | 明确违禁无法改到安全 | 仍可进 Feed，标 FATAL | 红 + 强烈建议勿投 |

### 6.5 词表种子类目（可扩展，运营可配）

- 塑身 / 情趣内衣与配件  
- 战术刀 / 防身器械（改写为户外工具语义）  
- 部分按摩/成人向器械  
- 其它政策高危（按 Google 政策清单迭代）

### 6.6 与标题重构的顺序

**建议顺序：** 先抽属性 → 标题重构 → **再跑敏感过滤**（避免漂亮标题里残留战术刀等词）→ 再写 Feed。

## 7. S7 — 图片（按风险全面设计）

### 7.1 为什么必须做

Shopping **看图权重极高**。1688 图常见：中文水印、价格贴、牛皮癣字、批发站 UI、过度修图。  
脏图 → 拒审 + CTR 差；本阶段做 **检测 + 去脏 + 干净主图**，生活方式大片后置。

### 7.2 品类 × 风险 × 处理策略

| 品类倾向 | 常见问题 | 检测信号 | 解决方案（本阶段） | 失败时 |
|----------|----------|----------|-------------------|--------|
| **服饰 / 鞋服 / 配饰** | 中文码数贴、模特图带店铺水印、多色拼图难辨主色 | OCR 中文；水印位；域名含 1688/alicdn 等 | 去水印；优先单品清晰主图；可选白底 | 原图 + WARN「疑似脏图」 |
| **3C / 数码 / 汽配** | 参数表截图当主图、中文规格字、多 SKU 拼图 | OCR 密集文字；非白底商品占比 | 去水印；若判定「纯文字参数图」→ WARN 建议换主图；不强行乱生成假机身图 | WARN；不阻断 |
| **美妆 / 个护** | 中文成分表、批文号水印 | OCR 中文 | 去水印；保留包装主体清晰度 | WARN |
| **刀具 / 户外 / 敏感外形** | 图与文案不一致、过于杀气的展示 | 与 S6 类目联动 | 图侧不「美化违禁」；文案侧软化；必要时 adult | 按 S6 |
| **通用** | 主图缺失、过小、非 HTTPS | HTTP 头 / 尺寸 | FATAL：无主图；WARN：过小 | 无主图仍 FATAL |

### 7.3 处理流水线

```
候选主图 URL（Shopify image）
    → 风险打分：域名黑名单 / OCR 中文与贴纸 / 水印模型（能力可分期）
    → 若高风险：
         调用去水印（复用现有 image_processor）
         可选：抠图 → 白底（服饰/标品优先；参数图谨慎）
         上传可公网 CDN
         Feed.image_link = 新 URL
         AUTOFIX 日志
    → 若处理失败：
         保留原图 + WARN
    → 若无图：
         FATAL
```

### 7.4 白底策略（本阶段）

| 策略 | 说明 |
|------|------|
| **默认偏好** | 服饰/标品：去水印后 **尽量白底**（Google 习惯） |
| **非强制一刀切** | 场景图若已干净且无中文，可保留并 INFO |
| **不做** | 大批量欧美生活场景 Mockup（蓝海扩展，后置） |

### 7.5 日志与报告

- 「已去除中文水印并替换主图」

## 10. 验收标准（本阶段完成定义）

1. **服饰缺尺码** → Feed 含 `One Size`，日志有邀功条。  
2. **无颜色** → 先 LLM/抽取，再 `Multicolor`（或 As Shown），有真色绝不一刀切。  
3. **无 GTIN** → `identifier_exists=false` + 非 myshopify 的 brand，日志有「无码通道」。  
4. **标题** → 英文结构化；App 能看原标题 vs 广告标题。  
5. **敏感示例** → 战术刀类文案被软化；内衣类带 `adult=yes`。  
6. **脏图示例** → 尽量去水印并换 `image_link`；失败必 WARN。  
7. **价币种** → 不一致国家仍拦截。  
8. **报告** → autofixed / warnings / fatals 可统计；黄灯/红灯语义正确。
