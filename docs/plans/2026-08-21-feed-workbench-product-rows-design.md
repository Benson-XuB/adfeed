---

## 1. 决策锁定

| 问题 | 选择 |
|------|------|
| 页面总表一行是什么？ | **商品行**（一件 Shopify 商品） |
| 生成 Feed 之后？ | 用户能 **预览该商品对应的全部 Feed 条目**（通常多 SKU），并 **编辑广告字段** 后写回、更新当前稳定 Feed |
| 是否整页改 XML？ | **否** — 改主人层（`feed_title` / color / size / feed 主图等） |
| 对外 URL？ | 仍一条稳定「当前」URL；覆盖前打快照（见 08-20 设计） |

## 2. 信息架构

```text
┌─────────────────────────────────────────────┬──────────────────┐
│ 全局：市场/渠道 + 标题公式（仅预填）+ 描述清洗   │ 合规摘要         │
│ 总表（商品行）：图 / 原标题 / 状态 / Edit       │ Live Feed URL    │
│                                             │ 下载 / 复制 / 快照 │
└─────────────────────────────────────────────┴──────────────────┘
                         │
                         ▼ Edit / 预览
              ┌──────────────────────────────┐
              │ 右侧抽屉（不整页跳转）          │
              │ 提示：只影响广告 Feed，不改店面  │
              │ 该商品下 Feed 条目列表（SKU）   │
              │ 标题 / 色 / 码 / 主图 / …      │
              │ 取消 | 保存并应用到当前 Feed    │
              └──────────────────────────────┘
```

---

## 3. 两层表的分工

| 层 | 粒度 | 内容 | 操作 |
|----|------|------|------|
| **总表** | 商品行 | Shopify 图、原标题、渠道标记、Ready / Missing 状态 | 搜索、筛选、进入 Edit |
| **抽屉内列表** | SKU / Feed item 行 | 该 `item_group`（或 product）下写入当前 Feed 的条目：图、广告标题、color、size、价、问题标记 | 行内改 → 保存 |

状态来源：质量报告汇总到商品（任一条目 FATAL → Missing；否则 Ready 或 Warn）。

---

## 4. 编辑与公式优先级

1. **单行/SKU 覆盖 > 全局标题公式**  
2. 全局公式只用于 **默认预填/预览**，保存写入广告标题主人层；禁止在 `feed_generator` / `title_guard` 出口再叠 `pin_*`  
3. color 保持纯色；花色走 pattern；品牌仍走店铺确认，不在行内改成供应商名  
4. 保存 → 写主人层 → 「应用到当前 Feed」（与现有 generate / row_patch 管道一致，带快照）

抽屉首版字段（建议）：广告标题、color、size、Feed 主图；GPC / Custom Label 可二期。

---

## 5. 与 08-20 已落地能力的关系

| 已有 | V2 用法 |
|------|---------|
| Feed preview API（分页 SKU） | 抽屉内按 `product_id` / item_group 过滤 |
| row_patch / feed_title / image_patch | 抽屉保存 |
| snapshots + restore | 右侧「历史版本」入口 |
| 合规诊断 API | 右侧合规卡 |

V2 主要是 **把能力收成工作台主界面**，不是另起一套改 XML 的产品。

---

## 6. 明确不做（本版）

- 总表直接 SKU 海量行当唯一视图（细改只在抽屉）  
- 整页 XML 编辑器、多套并行可编辑版本 URL  
- 标题公式在出口叠层；假 GTIN / 静默 eprolo  
- 安检大动画 / Magic Bar（北星未完成字段债前）

---

## 7. 验收（设计层）

1. 总表能按商品扫完店货，状态可读  
2. 生成后点某商品，能看见 **该商品对应的全部 Feed 条目**  
3. 改一条广告标题/色/码并保存后，当前 Feed 与预览一致  
4. 店面商品标题不被改掉  
5. 裤/裙/夹克各一：广告标题仍像人会点的衣服，不像属性墙
