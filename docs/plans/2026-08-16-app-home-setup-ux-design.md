# 2026-08-16 App Home 生成前主路径 UX

Field contract: docs/plans/2026-08-14-feed-field-contract.md  
North Star: docs/plans/2026-08-12-mvp-north-star.md

## Goal

生成前主路径固定为：**媒体 → 市场 → 选品表（核心）→ 店铺警告**。选品是唯一主舞台，用一张表 + 清晰表头完成勾选，不为产品再切分块卡片。

## IA

1. **投放哪里** — Google / Meta / TikTok + 目标市场（同一设置区，短说明）  
2. **选择要生成 Feed 的商品** — 全表：勾选 | 图 | 商品 | 规格 | 状态 | 广告图；搜索+全选在表头工具行  
3. **店铺需要设置** — 广告品牌门禁、币种不一致、安检警告；条码/成本折叠为次要  

生成后结果页（方案 A）仍排在最上。配额缩成设置区一行。

## Non-goals

不改 Feed 字段逻辑；不静默 eprolo；不做 Magic Bar。
