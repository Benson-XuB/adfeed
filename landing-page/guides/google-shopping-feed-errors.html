Google Shopping Feed Errors: How to Find and Fix Them

Short answer: most feed problems show up as missing or dirty attributes—title, brand, image, color/size, identifiers— long before you notice spend waste. Check the feed file itself first.

Common Google Shopping feed errors

Noisy or supplier-style titles

Titles stuffed with “hot sale,” factory codes, or every size in one string read like attribute walls. Shoppers and Shopping surfaces need a short, clear product name—with this offer’s color/size once, not a dump.

Missing or wrong brand

Empty brand, or a 1688 factory name as brand, is a frequent failure for import-heavy Shopify stores. Use the brand your storefront actually sells under.

Color / size gaps

Apparel and footwear usually need consistent color and size per offer. Dirty option text (“Brown Style 1”) should not live in color—keep color clean; put pattern elsewhere.

Identifier / GTIN mistakes

Invented barcodes are worse than no barcode. If you lack a real GTIN, use compliant “identifier exists = no” with a real brand—never fabricate codes to silence warnings.

Missing primary image

No usable image_link (or broken URLs) blocks offers quickly. Main image must be fetchable.

Price / availability mismatches

Feed price or stock that doesn’t match the landing page triggers issues and trust problems. Keep the feed in sync with the live PDP.

How to diagnose the problem

  1. Run your public feed through the Feed Checker.
  2. If products are already in Merchant Center and disapproved, use the Issue Diagnostic to see account vs feed patterns.
  3. Fix catalog / feed data; regenerate; re-check before scaling ads.
